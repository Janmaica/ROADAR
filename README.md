# ROADAR

**Development and Evaluation of an Offline-Capable Android Application for Pothole Detection Using a Fine-Tuned YOLO26n Model**

ROADAR is an Android application under development that aims to detect road potholes in real time using a fine-tuned YOLO26n object detection model.

## Planned Features

- Offline pothole detection using an Android camera
- Real-time bounding boxes and confidence scores
- GPS-based pothole reporting
- Local database storage
- Map visualization of pothole reports
- Synchronization when internet connectivity becomes available
- On-device performance evaluation

## Technology Stack

- Kotlin
- Jetpack Compose
- CameraX
- YOLO26n
- Room Database
- WorkManager
